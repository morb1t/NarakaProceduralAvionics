# Naraka Procedural Avionics

Procedural avionics core for Kerbal Space Program.

Provides a resizable avionics core based on Procedural Parts with configurable electrical capacity, science data storage, sample storage and integrated science instrumentation.

RP-1 is not required.

## Requirements

ModuleManager  
Procedural Parts

## Optional Support

Realism Overhaul  
RealFuels  
Kerbalism  
MechJeb2  
Probes Before Crew  
DMagic Orbital Science  
SpaceDust  
Textures Unlimited

## Features

Procedural diameter, length and shape  
Configurable battery capacity  
Configurable science storage  
Configurable sample storage  
Integrated configurable science instruments  
Flight Telemetry experiment  
Low-power avionics hibernation  
Built-in internal communications for RO installations  
RealFuels and Realism Overhaul support  
Kerbalism science integration  
MechJeb integration  
DMagic Orbital Science support  
SpaceDust integration  
Textures Unlimited support

## Installation

Drag and drop `GameData/NarakaProceduralAvionics` into your Kerbal Space Program directory.

The installed mod should be located at:

`GameData/NarakaProceduralAvionics/`
